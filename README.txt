BRAIN-UP — стартовый интерфейс Telegram Mini App

Содержимое:
- index.html — адаптивный интерфейс в стиле UpgradePro;
- каталог Brainrots с ценами из списка пользователя;
- поиск по каталогу;
- выбор цели Upgrade и отображение расчётного шанса.

Важно:
Это фронтенд-прототип. Баланс, аккаунты Telegram, серверный инвентарь,
проверка результата и сохранение данных ещё не подключены.
Для публикации нужен HTTPS-хостинг и серверная проверка Telegram initData.
В прототипе нет реальных денежных ставок, пополнений или вывода средств.
